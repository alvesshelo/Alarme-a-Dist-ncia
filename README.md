# Alarme-a-Distancia
Alarme à Distância é um app que ajuda você a não perder o ponto durante uma viagem. Defina seu destino e o aplicativo monitora sua localização, acionando um alarme automaticamente quando você estiver chegando ao local escolhido.

## Stack de Tecnologias
Backend: PHP estruturado com sessões ativas e javascrpit.
Banco de dados: SQL com PDO para segurança.
Frontend: HTMLS, CSS usando boodstrap.
